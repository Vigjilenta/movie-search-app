# Movie Search App

A simple web application to search and save your favorite Studio Ghibli films.

## **Features**
* **Search**: Find movies by title or director.
* **Favorites**: Save movies to your browser so they stay saved when you refresh.
* **Dark Mode**: Switch between light and dark themes.
* **Details**: Click on any movie to see the full description and rating.


## **Tools Used**
* **JavaScript** (Fetch API and LocalStorage)
* **HTML & CSS** (Grid and Flexbox)
* **Ghibli API** (Movie Data)
